# Example Audio Files

Place your test audio stems here for development.

## Suggested Test Files

For best testing, include:

1. **Simple monophonic** - Single instrument, clear melody
   - Vocal line (isolated)
   - Bass guitar stem
   - Lead synth

2. **Simple polyphonic** - Chords, but not too complex
   - Acoustic guitar strumming
   - Simple piano part
   - Pad synthesizer

3. **Complex polyphonic** - Challenging material
   - Piano solo with chords
   - String section
   - Complex keyboard part

4. **Edge cases**
   - Very quiet audio
   - Distorted guitar
   - Fast runs/arpeggios

## How to Get Test Stems

### Option 1: Export from Your DAW
- Solo a track in your DAW
- Export as WAV or MP3
- Use 44.1kHz or 48kHz sample rate

### Option 2: Use Built-in Stem Separation
- **Logic Pro**: Stem Splitter plugin
- **Ableton Live 12**: Track Separation feature
- **FL Studio**: Stems feature

### Option 3: Online Tools
- **Moises.ai** - Free stem separation
- **Lalal.ai** - High-quality separation (paid)
- **Splitter.com** - Basic free separation

## File Naming Convention

Use descriptive names:
- `bass_funk_120bpm.wav`
- `piano_ballad_slow.wav`
- `vocal_melody_female.wav`

This helps track what works well and what doesn't!
